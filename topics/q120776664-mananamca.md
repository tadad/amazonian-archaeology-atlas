# Manañamca

## Discovery summary

Manañamca es una diosa mencionada dentro del Manuscrito de Huarochirí. Según el manuscrito, se la describe como una mujer demonio. Asimismo, dicha diosa es considerada consorte del dios Huallallo Carhuincho y, al igual que este último, tiene el control total sobre el fuego.​
